# Samples

> **TL;DR** Small, regenerable outputs: a seamless music loop (score + audio + JS module) and two SFX packs. They are made by this program, and the same commands give the same files.

| Folder | What | Made with |
|---|---|---|
| `mellow-space-loop/` | 16-bar seamless loop (99 BPM, about 39 s) as `.8bt`, `.ogg` (Vorbis q0) and an ES module | `8bms compose --style mellow-space --bars 16 --seed 1 --loop -o mellow-space-loop.8bt` (title edited), then `8bms render … --seamless`, then `8bms export … --js` |
| `sfx-platformer/` | 10 SFX (jump, coin, powerup, 1up, hit, hurt, death, door, step, levelup), a `manifest.json` and a Howler-style `sprite.wav`/`sprite.json` | `8bms soundpack platformer --sr 22050 -o sfx-platformer` |
| `sfx-ui/` | 7 UI sounds and a `manifest.json` | `8bms soundpack ui --sr 22050 --no-sprite -o sfx-ui` |

The repo's `demo.ogg` is `8bms render demo -o demo.wav`, encoded to Vorbis q0 to keep it small: `ffmpeg -i demo.wav -c:a libvorbis -q:a 0 demo.ogg`.

```js
import { createPlayer } from './mellow-space-loop/mellow-space-loop.js';
createPlayer(new AudioContext(), { loop: true }).start();
```
